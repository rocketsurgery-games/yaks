Root of the exploration herd for using yaks as an unopinionated coordination substrate for agents and humans, across harnesses (Pi minimal, Claude Code rich, Zed panel). Goal is primitives and high-leverage CLI/TUI affordances, not a prescribed methodology. Skills stay no more prescriptive than necessary.

Design tenets
- Files authoritative, index derived (existing invariant).
- Same substrate for agents and humans. Both read and write it.
- Methodology-agnostic. Yaks supplies primitives (state, parentage, deps, refs, labels, notes/comments, source). Workflows compose on top. We do not bake one in.
- Portable across harnesses. A minimal harness uses yaks as durable memory and log. A rich harness uses it as a shared blackboard across subagents. Degrade gracefully. Assume nothing about subagents or worktrees.
- Evidence over assertion (from pstack). A yak is not shorn without recorded evidence in its notes.
- Keep the state machine tiny. Push coordination nuance to labels, fields, and comments, not new states.

Exploration areas (candidate child subtrees)
1. Coordination patterns. Blackboard via parent/child + deps + notes. Claim via shave. One writer per yak. Human-in-the-loop validation channel. Fan-out research and summarization (parent is the question, children are slices, notes are summaries). Lightweight planning as a tree of yaks.
2. Query affordances (read side). Comments and notes since a timestamp across a filter. Recency and activity feeds. Rich JSON that exposes notes, timestamps, verdicts.
3. Bulk and write affordances. Bulk label and metadata edits by id-list or dynamic filter. Bulk state transitions. Filter-driven mutations with dry-run.
4. Metadata for coordination. Which labels, fields, and conventions carry coordination signal. Note authorship and agent attribution. Verdict and evidence fields as a convention.
5. Harness integration. Pi vs Claude Code mapping. MCP surface. Per-repo agent context. The degradation model.
6. Meta and evaluation. Dogfood on this herd. Measure whether an affordance cuts turns and herding drudgery before promoting it.
