Recover the code-to-yak link from git instead of storing commit hashes in the yak (which is circular). Two joins: (a) the yak files own history, git log --follow over the yak path shows the commit that moved it into shorn alongside the code; (b) the yak id in commit messages (team mode), via git log --grep. A yaks commits <id> helper composes both. Blame-equivalent: from a code line, git blame to commit to yak id or the yak file that commit touched. Keyword search to candidates is largely existing search. Optional forward links via branch/PR frontmatter. Needs id-to-path (yaks-aa49); folds yaks-4b52, yaks-d695.
