Define yak ops: create, set-title/priority/type/source, add/remove-label, set-parent, add/remove-dep, add-note, transition (shave/shorn/regrow/slaughter/revive), attach. Each op = {type, author, wall timestamp (display only), Lamport clock, payload, nonce}; id = hash(op). Ops batch into an OperationPack (one author/session) stored as a git blob; a tree references it under /ops (+ /media); a commit chain per yak under refs/yaks/<id>. Compile = replay ops in deterministic order (Lamport clock, then op-pack id tiebreak; enforce clocks respect the DAG) onto empty state to get the current snapshot. Note that status stops being a directory and becomes a compiled field.
