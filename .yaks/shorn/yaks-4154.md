Consolidation MVP linchpin. yaks create today always stamps the single config prefix (create then generate_id(root, cfg.prefix)). In a farm holding several herds, create must pick which herd a new yak joins. Add --prefix P to yaks create and a prefix field on NewTask; fall back to cfg.prefix when absent. generate_id already takes the prefix param, so the change is small. Spelling stays --prefix (accurate for which id stem regardless of herd/farm vocabulary; can gain a --herd alias once naming settles, see the docs/naming child).
